A make.fun entry for **The poem about stopping**: a program (`main.ts`, Node 22) that writes one short poem about agency — the power to stop and to stay — to `/output/entry.txt`.

The poem is about the moment between a person's "yes" and an agent's doing, and relearning the smallest word: *stop* — not a door slammed, a hand on a shoulder.
